# Aria UI handoff

This prototype uses a 14/16/20/28/36 px type scale, an 8 px spacing rhythm, 8 px control radius and 12 px container radius. Body copy is 14–16 px; 12 px is reserved for supporting metadata.

Component variants:

- Buttons: primary, secondary, icon-only, disabled.
- Inputs: text, select, date and search with visible focus.
- Cards: result, state, KPI, source definition and admin card.
- Overlays: modal, drawer and contextual inspector.
- Tables: business result and technical schema.
- Status: available, limited, simulated, partial, restricted and error.

Action icons use the inline SVG stroke/fill language already shared by the workspace. Emoji are not used for result actions. Business metadata stays in the result layer; SQL, physical schema and debug information stay in technical details.
